**Русский** · [English](README.en.md)

JumpDeck собирает ассеты, скрипты, настройки, объекты сцены и сохранённые поисковые
запросы в одной панели Unity Editor. Разложи пины по декам для UI, левел-дизайна,
освещения или других задач и закрепи панель в удобном месте.

- **Быстрый доступ:** нажми на пин, чтобы найти или открыть объект.
- **Свои деки:** меняй порядок пинов, размер иконок и действие по клику.
- **Live Pins:** запускай сохранённый поиск по загруженным сценам.
- **Обмен:** экспортируй отдельную деку в файл `.jumpdeck`.

**MIT · Unity 2023.2+ и Unity 6**. Проверено на Unity 2023.2.22f1 и Unity 6 (6000.6.3f1).

## Установка

В **Window → Package Manager → Add package from git URL** вставь:

```text
https://github.com/PMakagon/JumpDeck.git
```

Открой **Window → JumpDeck** или нажми **Alt+J**.
Горячую клавишу можно сменить в шестерёнке: нажми **Open shortcut** и введи новое сочетание.
Закрепи окно там, где тебе удобно.

## Собери деку

1. Создай деку через **⚙ → Create deck** и назови её так, чтобы самому было понятно.
2. Перетащи туда объекты, которыми пользуешься чаще всего. Начни с нескольких,
   которые постоянно приходится искать.
3. Нажми на пин, чтобы перейти к объекту.

У каждого пина с объектом можно выбрать, что делает клик: **Ping**, **Open/Inspect**
или оба сразу. Настройка живёт в окне **⋮ → Click action**. Если в Inspector уже открыто
что-то нужное, выбирай **Ping**: он подсветит объект, а текущий выбор останется на месте.

Перетаскивай строку пина, чтобы менять порядок или переносить его в другую деку.
За заголовок можно перемещать саму деку. Перенос пина в Inspector или Scene
использует исходный объект. Отдельных ручек для этого нет.
С клавиатуры тоже можно: **↑ / ↓** для выбора пина, **Enter** для его запуска.

Кнопка **⋮** у деки открывает её название, настройки вида и команды. Размер иконок
и кнопок можно менять, а **Ping** и **Open/Inspect** включать отдельно.
По умолчанию обе кнопки скрыты. У каждой деки свой вид: например, крупные пины
для освещения и компактные для UI. Эти настройки сохраняются и при экспорте.
**Lock deck** защищает деку от изменений; пользоваться её пинами можно и после блокировки.

Общая шестерёнка **⚙** рядом с поиском открывает создание и импорт дек, показ количества пинов
и **Minimize headers**. Последний делает заголовки тонкими, без названий; пины остаются видны.

## Сохрани поиск по сцене

Если часто ищешь одно и то же, добавь **Live Pin** с запросом, например,
`h: t:Light` или `h: tag:Enemy`. Нажми на него, и он найдёт и выделит подходящие
объекты в загруженных сценах. В окне создания есть короткие примеры фильтров
с пояснениями и ссылка на справку Unity. Запрос можно поправить через **Edit Query…**.

## Где всё хранится и как поделиться

Деки лежат в `UserSettings/JumpDeck.asset`. Этот файл обычно не попадает в Git.
Декой можно поделиться с коллегой: выбери **⋮ → Export deck…** и отправь файл `.jumpdeck`.
Импорт есть в общей шестерёнке: он добавит новую деку, существующие останутся на месте.

Перед добавлением объекта сцены сохрани сцену. Когда она закрыта, её пины остаются
в деке и показывают, что сцену нужно загрузить.
